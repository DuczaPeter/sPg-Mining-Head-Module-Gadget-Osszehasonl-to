Adatforrás és fontos megjegyzés

Az oldal először lekéri a Star Citizen Wiki API aktuális alapértelmezett játékverzióját, majd ehhez a verzióhoz rögzítve tölti le a teljes mining laser, mining module és mining gadget katalógust.

Új LIVE mining eszközök automatikusan bekerülnek a listába. A meglévő eszközök értékei a következő megnyitáskor vagy a „Wiki API frissítése” gombbal az aktuális LIVE verzióból frissülnek.

A Clearcut, Deluge és Overrun 4.10 LIVE elemek. A 4.10-ben a Wiki API jelenlegi mining modifier mezői nem fednek le minden WeaponModifier-alapú teljesítményértéket, ezért ezeknél a 4.10 LIVE játékfájlokkal ellenőrzött kompatibilitási javítás egészíti ki az API-adatot.

A HTML tartalmaz beágyazott tartalék adatokat is. Az aktuális adatforrás állapota felül, az API állapotsorában látható, ezért ezt nem ismétli meg minden egyes sorban.

Az oldal nem csak az előre ismert neveket tölti be. A teljes mining-laser és mining-modifier katalógus mellett minden Mining classification alá sorolt új elemet is automatikusan megkeres. Ha az új elem a Wiki API-ban mining specifikációval jelenik meg, a következő megnyitáskor vagy frissítéskor magától bekerül. A bevásárlólista a UEX aktuális itemár- és termináladataiból keresi meg azt a beszerzést, amelyhez a legkevesebb külön állomáson, városban, outposton vagy POI-n kell megállni. Az ár csak akkor számít, ha több, teljesen egyenértékű hely közül kell választani.

A módosítók itt külön-külön szerepelnek. A program szándékosan nem ad össze loadout-értékeket, mert a stacking és a tényleges játékon belüli alkalmazás verziófüggő lehet.
